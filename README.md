# obhrm-research-collaboration-team

**OBHRM 研究协作团** · 研究全流程多智能体协作系统

> 本仓库是 **公开落地页 / 产品说明**。完整包（智能体与技能）通过 **WorkBuddy 专家中心** 分发与安装；仓库本身不放包源码，仅作说明与入口。

Part of the [Lucewalk Lumen](https://github.com/Lucewalk-Lumen/about-me) collection.

## What it is

An OBHRM (Organizational Behavior & Human Resource Management) research collaboration system where **seven agents** cover every stage of the research lifecycle:

- Topic modeling
- Literature review
- Paper writing
- Grant proposals
- Data analysis
- Journal selection & submission
- Revision / response to reviewers

EndNote / Zotero library import is supported throughout.

## How to get & use it

1. Open **WorkBuddy** and go to the **Expert Center**;
2. Search for / install **obhrm-research-collaboration-team**;
3. Invoke the agent for the stage you need and start your research collaboration.

> The package is not provided here as source code; this repository only describes its capabilities, method and how to obtain it.

## Security baseline

No hardcoded keys · least-privilege · input-bounds checks · operation audit.

## Platform portability

These agents are delivered in the WorkBuddy format and will not run as-is on another platform. But this repo and the portal document the method, prompts and structure in plain text, so they can be re-implemented as a reference design on another agent framework if you migrate. The knowledge (scales, theories, workflows) is portable even if the runtime isn't.
